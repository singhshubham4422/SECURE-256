# Encryption-Decryption with Python
Encryption and decryption are fundamental processes in securing data. In this project, we will explore the AES- 256, 3DES,RSA,ECC algorithms for securing files.
The primary objective of the application is to develop a Graphical User Interface (GUI) program that facilitates the seamless encryption and decryption of files. The program is designed to optimize user experience through an intuitive interface, incorporating various functionalities.
A pivotal feature of the program is its sophisticated file selection mechanism, empowering users to effortlessly browse their system and designate the specific files they intend to encrypt or decrypt. In an effort to bolster security, the program prompts users to establish a password of their choosing. This password functions as a critical element in both the encryption and decryption processes, significantly contributing to the overall security of user files.
A noteworthy characteristic of the program lies in its adaptability, allowing users to select from a diverse array of encryption algorithms. These options encompass advanced algorithms such as AES-256, 3DES, RSA, and ECC. This level of flexibility enables users to tailor their file protection strategy according to their distinct requirements and preferences.
The GUI features a dedicated workspace that provides users with pertinent information throughout the encryption or decryption process. This information includes details such as the selected file, the chosen encryption algorithm, memory usage, processing time, and the real-time status of the ongoing operation. Such transparent feedback enhances the user experience by offering insight into the program's activities.
